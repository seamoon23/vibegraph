# VibeGraph Privacy Policy

Effective date: July 9, 2026

This policy applies to the VibeGraph Chrome Extension.

## Korean

### 1. VibeGraph가 하는 일

VibeGraph는 사용자가 열어 둔 AI 대화 페이지에서 사용자가 직접 캡처를 실행했을 때 대화 내용을 읽고, 로컬에서 평가 초안과 리포트를 만드는 Chrome 확장 프로그램입니다.

지원 대상은 현재 Claude, ChatGPT, Gemini 웹 대화 페이지입니다.

### 2. 처리하는 데이터

VibeGraph는 기능 제공을 위해 다음 정보를 로컬에서 처리할 수 있습니다.

- 사용자가 캡처한 AI 대화의 메시지 내용
- 대화 페이지의 제목, URL, AI 서비스 출처, 캡처 시각
- 사용자가 입력하거나 수정한 프로젝트명, 작업명, 태그, 메모
- 자동 평가 결과, 축별 점수, 리포트 요약, Prompt Smell 진단
- 사용자가 직접 붙여넣은 AI 정밀 평가 결과
- 확장 프로그램 설정값

캡처한 대화 안에 이름, 이메일, 업무 내용, 코드, 개인 메모 등 민감하거나 개인적인 정보가 포함되어 있다면, 해당 내용도 로컬 리포트에 포함될 수 있습니다.

### 3. 데이터 사용 목적

VibeGraph는 위 데이터를 다음 목적에만 사용합니다.

- 사용자가 선택한 AI 대화 캡처
- 캡처한 대화의 자동 평가 초안 생성
- 개별 리포트, 전체 리포트, 성장 추적 리포트 생성
- AI 정밀 평가용 프롬프트 생성 및 복사
- 사용자가 요청한 내보내기 또는 관리 기능 제공

VibeGraph는 사용자 데이터를 광고, 리타게팅, 사용자 추적, 프로파일링, 판매 목적으로 사용하지 않습니다.

### 4. 저장 위치와 전송

VibeGraph는 캡처한 데이터와 리포트 데이터를 사용자의 브라우저 로컬 저장소인 `chrome.storage.local`에 저장합니다.

VibeGraph는 자체 서버를 운영하지 않으며, 캡처한 대화나 리포트를 개발자 서버 또는 제3자 서버로 자동 전송하지 않습니다. 또한 분석 도구, 광고 SDK, 원격 코드 실행을 사용하지 않습니다.

단, 사용자가 AI 정밀 평가 Wizard에서 생성된 프롬프트를 복사하여 Claude, ChatGPT, Gemini 등 외부 AI 서비스에 직접 붙여넣는 경우, 그 사용자가 붙여넣은 내용은 해당 외부 서비스의 약관과 개인정보 처리방침의 적용을 받습니다. 이 전송은 VibeGraph가 자동으로 수행하지 않으며 사용자의 명시적 행동으로만 발생합니다.

### 5. 공유

VibeGraph는 캡처한 대화, 리포트, 평가 결과를 개발자나 제3자에게 공유하지 않습니다.

사용자가 리포트를 복사, 내보내기, 공유하거나 외부 AI 서비스에 직접 붙여넣는 경우에는 사용자의 선택에 따라 데이터가 외부로 이동할 수 있습니다.

### 6. 보관 및 삭제

VibeGraph 데이터는 사용자의 브라우저 로컬 저장소에 보관되며, 사용자가 삭제하거나 확장 프로그램을 제거할 때까지 남아 있을 수 있습니다.

데이터를 삭제하려면 Chrome에서 `chrome://extensions`를 열고 VibeGraph를 제거하거나, Chrome의 사이트/확장 프로그램 저장 데이터 관리 기능을 사용할 수 있습니다. VibeGraph 안에 개별 기록 삭제 기능이 제공되는 버전에서는 확장 프로그램 UI에서도 저장된 세션을 삭제할 수 있습니다.

### 7. 권한 사용

VibeGraph는 다음 Chrome 확장 권한을 기능 제공에 필요한 범위에서 사용합니다.

- `sidePanel`: VibeGraph 패널 UI를 표시합니다.
- `storage`: 캡처 기록, 리포트, 설정을 로컬에 저장합니다.
- `activeTab`: 사용자가 현재 보고 있는 AI 대화 탭을 확인합니다.
- `scripting`: 지원되는 AI 대화 페이지에서 캡처 스크립트를 실행합니다.
- 호스트 권한: Claude, ChatGPT, Gemini 대화 페이지에서 사용자가 요청한 캡처 기능을 제공합니다.

### 8. Chrome Web Store Limited Use Disclosure

VibeGraph는 Chrome 확장 API를 통해 받은 정보를 확장 프로그램의 단일 목적과 사용자에게 보이는 기능을 제공하거나 개선하는 데에만 사용합니다.

VibeGraph는 사용자 데이터를 광고 목적으로 사용하거나 전송하지 않으며, 판매하지 않고, 개발자가 사용자의 캡처 내용을 읽지 않습니다. 사용자가 지원 요청 등을 위해 직접 데이터를 제공하는 경우에만 해당 요청 처리를 위해 제공된 내용을 확인할 수 있습니다.

## English

### 1. What VibeGraph Does

VibeGraph is a Chrome Extension that lets users capture AI conversations they are viewing and create local evaluation drafts and reports.

The currently supported AI conversation pages are Claude, ChatGPT, and Gemini.

### 2. Data Processed

VibeGraph may process the following data locally to provide its features.

- Messages from AI conversations that the user chooses to capture
- Conversation page title, URL, AI service source, and capture time
- Project name, task name, tags, and notes entered or edited by the user
- Automatic evaluation results, axis scores, report summaries, and Prompt Smell diagnostics
- AI precision evaluation results pasted by the user
- Extension settings

If a captured conversation includes names, email addresses, work information, code, private notes, or other personal or sensitive information, that content may be included in the local report.

### 3. How Data Is Used

VibeGraph uses this data only to provide user-facing features.

- Capturing AI conversations selected by the user
- Creating automatic evaluation drafts from captured conversations
- Creating session reports, overall reports, and growth tracking reports
- Generating and copying prompts for AI precision evaluation
- Providing export and management features requested by the user

VibeGraph does not use user data for advertising, retargeting, tracking, profiling, or sale.

### 4. Storage and Transmission

VibeGraph stores captured data and report data in the user's browser local extension storage, `chrome.storage.local`.

VibeGraph does not operate a backend server and does not automatically transmit captured conversations or reports to the developer or to third-party servers. VibeGraph does not use analytics SDKs, advertising SDKs, or remote code execution.

If the user copies a prompt generated by the AI precision evaluation Wizard and manually pastes it into an external AI service such as Claude, ChatGPT, or Gemini, the pasted content is handled under that service's terms and privacy policy. VibeGraph does not perform this transfer automatically; it only happens through the user's explicit action.

### 5. Sharing

VibeGraph does not share captured conversations, reports, or evaluation results with the developer or third parties.

Data may leave the user's device only if the user chooses to copy, export, share, or paste it into an external service.

### 6. Retention and Deletion

VibeGraph data remains in the user's browser local extension storage until the user deletes it or removes the extension.

To delete extension data, open `chrome://extensions` in Chrome and remove VibeGraph, or use Chrome's site and extension storage management features. If the installed VibeGraph version provides in-app deletion controls, saved sessions can also be deleted from the extension UI.

### 7. Permissions

VibeGraph uses the following Chrome extension permissions only as needed for its features.

- `sidePanel`: Shows the VibeGraph panel UI.
- `storage`: Stores captured sessions, reports, and settings locally.
- `activeTab`: Identifies the AI conversation tab the user is viewing.
- `scripting`: Runs the capture script on supported AI conversation pages.
- Host permissions: Provide user-requested capture features on Claude, ChatGPT, and Gemini conversation pages.

### 8. Chrome Web Store Limited Use Disclosure

VibeGraph uses information received from Chrome extension APIs only to provide or improve its single purpose and user-facing features.

VibeGraph does not use or transfer user data for advertising, does not sell user data, and does not allow the developer to read captured user content. The developer may review data only when the user voluntarily provides it for support or a similar user-initiated request.
