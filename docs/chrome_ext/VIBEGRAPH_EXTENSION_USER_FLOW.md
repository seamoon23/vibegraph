# VibeGraph Chrome Extension 사용자 흐름 가이드

이 문서는 VibeGraph Chrome Extension MVP가 사용자의 눈에 어떻게 보이고, 내부적으로 어떤 흐름으로 동작해야 하는지 이해하기 위한 가이드다.

이미지 대신 ASCII 다이어그램과 화면 흐름 중심으로 설명한다.

---

## 1. 한 줄 정의

VibeGraph Chrome Extension은 Claude, ChatGPT, Gemini 같은 웹 AI 대화창에서 진행한 작업 대화를 저장하고, 나중에 회고할 수 있도록 도와주는 로컬 우선 브라우저 확장이다.

```text
AI와 대화하며 작업한다
        ↓
현재 대화를 캡처한다
        ↓
프로젝트/작업명/태그를 붙인다
        ↓
4가지 기준으로 점수를 남긴다
        ↓
Markdown/JSON으로 보관하거나 리포트 프롬프트를 복사한다
```

---

## 2. local 방식과 web 방식 차이

### local 방식

```text
내 PC 프로젝트 폴더
  └─ Claude Code / Codex CLI / 터미널
      └─ 파일 수정, 테스트 실행, 커밋 준비
          └─ VibeGraph CLI로 리포트 생성
```

특징:

- 실제 파일 수정과 테스트 실행에 강하다.
- 로컬 개발환경을 그대로 쓴다.
- 개발자에게는 강력하지만, 초보자에게는 터미널/권한/설치 부담이 있다.
- 기존 VibeGraph CLI와 잘 맞는다.

### web 방식

```text
브라우저 AI 대화창
  └─ Claude.ai / ChatGPT / Gemini
      └─ 대화 내용을 확장 프로그램으로 캡처
          └─ 사이드패널에서 저장/점수/내보내기
```

특징:

- 설치와 접근이 쉽다.
- 사용자가 대화창 옆에서 바로 정리할 수 있다.
- Chrome Extension 배포와 사용자 온보딩에 유리하다.
- 웹페이지 DOM 변경에 취약할 수 있다.

핵심 차이:

```text
local = 실제 작업 수행에 강함
web   = 대화 수집/정리/사용자 접점에 강함
```

## 3. MVP 사용 시나리오

### 시나리오 A: Claude 웹 대화 저장

```text
1. 사용자가 claude.ai에서 코딩 작업 대화를 진행한다.
2. 작업이 어느 정도 끝난다.
3. Chrome 우측 상단의 VibeGraph 아이콘을 누른다.
4. 오른쪽 사이드패널이 열린다.
5. 사용자가 "현재 대화 캡처"를 누른다.
6. 대화 제목, URL, 메시지가 로컬에 저장된다.
7. 사용자가 프로젝트/작업명/태그를 입력한다.
8. 4축 점수를 입력한다.
9. Markdown 또는 JSON으로 내보낸다.
10. 필요하면 "리포트 프롬프트 복사"를 눌러 AI에게 회고 리포트를 요청한다.
```

## 5. 첫 실행 온보딩

첫 실행 화면은 기능 설명보다 불안감 제거가 우선이다.

```text
┌──────────────────────────────────┐
│ VibeGraph에 오신 것을 환영합니다 │
├──────────────────────────────────┤
│ AI 작업 대화를 저장하고          │
│ 나중에 회고할 수 있게 도와줘요.  │
│                                  │
│ 1. AI 대화창을 엽니다            │
│ 2. 현재 대화 캡처를 누릅니다     │
│ 3. 점수와 태그를 남깁니다        │

│ - 버튼을 누른 대화만 캡처합니다  │
│                                  │
│ [시작하기]                       │
└──────────────────────────────────┘
```

## 6. 기본 데이터 흐름

```text
[AI 웹 대화창]
      │
      │ 사용자가 캡처 버튼 클릭
      ▼
[Content Script]
      │
      │ 제목 / URL / 메시지 추출
      ▼
[Service Worker]
      │
      │ 확장 내부 이벤트 처리
      ▼
[Side Panel]
      │
      │ 사용자가 프로젝트/점수/태그 입력
      ▼
[Local Storage]
      │
      ├─ 세션 목록
      ├─ 메시지
      ├─ 점수
      ├─ 태그
      └─ 메모
```

```text
      └─ core/

            ├─ promptBuilder.ts

```

## 8. 지원 사이트 감지

```text
현재 탭 URL 확인
      │
      ├─ claude.ai             → Claude adapter 사용
      ├─ chatgpt.com           → ChatGPT adapter 사용
      ├─ chat.openai.com       → ChatGPT adapter 사용
      ├─ gemini.google.com     → Gemini adapter 사용
      └─ 기타                  → 지원하지 않는 페이지 안내
```

지원하지 않는 페이지 안내 예시:

```text
현재 페이지는 아직 지원하지 않습니다.
Claude, ChatGPT, Gemini 대화창에서 사용해 주세요.
```

## 10. 캡처 실패 상태

앱이 죽으면 안 된다. 실패 상태는 안내 중심으로 보여준다.

```text
┌─────────────────────────────┐
│ 대화를 찾지 못했어요        │
├─────────────────────────────┤
│ 가능한 원인                 │
│ - 지원하지 않는 페이지입니다 │
│ - 대화가 아직 로드 중입니다  │
│ - AI 서비스 화면이 바뀌었습니다 │
│                             │
│ 해볼 수 있는 것             │
│ 1. 페이지를 새로고침해 주세요 │
│ 2. 대화가 보이는 상태에서 다시 시도해 주세요 │
│ 3. 제목/메모만 수동 저장할 수 있습니다 │
│                             │
│ [다시 시도] [수동 저장]     │
└─────────────────────────────┘
```

## 11. 점수 입력 UX

각 항목은 0~25점이다.

```text
┌─────────────────────────────┐
│ 4축 점수                    │
├─────────────────────────────┤
│ 원샷 달성률                 │
│ 처음 요청으로 얼마나 잘 됐나요? │
│ [ 20 ] / 25                 │
│                             │
│ 컨텍스트 유지력             │
│ 중간에 맥락이 잘 유지됐나요? │
│ [ 21 ] / 25                 │
│                             │
│ 주도권 제어력               │
│ 내가 방향을 잘 잡았나요?    │
│ [ 18 ] / 25                 │
│                             │
│ 프롬프트 선명도             │
│ 요청이 충분히 구체적이었나요? │
│ [ 22 ] / 25                 │
│                             │
│ 총점: 81 / 100              │
└─────────────────────────────┘
```

점수 입력 전에는 다음처럼 표시한다.

```text
아직 평가 전입니다.
작업이 끝난 뒤 가볍게 점수를 남겨 보세요.
```

## 12. 리포트 프롬프트 복사 흐름

```text
[리포트 프롬프트 복사]
      │
      ▼
세션 정보를 기반으로 평가 프롬프트 생성
      │
      ▼
클립보드에 복사
      │
      ▼
사용자가 Claude/ChatGPT/Gemini에 붙여넣기
      │
      ▼
AI가 VibeGraph 형식 JSON 리포트 생성
```

성공 안내:

```text
프롬프트를 복사했어요.
이제 AI 대화창에 붙여넣어 리포트를 받아보세요.
```

## 14. 사용자에게 보여줄 핵심 문구

### 개인정보

```text
내 대화는 내 브라우저에만 저장됩니다.
VibeGraph는 서버로 대화를 보내지 않습니다.
버튼을 누른 대화만 캡처합니다.
```

### 첫 사용

```text
AI 작업이 끝났다면 현재 대화를 캡처해 보세요.
프로젝트와 태그를 붙여두면 나중에 작업 흐름을 다시 찾기 쉽습니다.
```

### 빈 목록

```text
아직 저장된 세션이 없습니다.
Claude, ChatGPT, Gemini 대화창에서 현재 대화 캡처를 눌러 첫 기록을 만들어 보세요.
```

### 지원하지 않는 사이트

```text
현재 페이지는 아직 지원하지 않습니다.
Claude, ChatGPT, Gemini 대화창에서 사용해 주세요.
```

## 15. MVP에서 제외할 것

이번 단계에서는 하지 않는다.

- 외부 AI API 호출
- 자동 백그라운드 감시
- 구독 결제
- 클라우드 동기화
- VSCode 내부 Claude Code 패널 직접 연동
- 모든 AI 사이트 완벽 지원

이유:

```text
처음 목표는 크롬 확장 개발/배포 사이클을 배우고,
웹 AI 대화 저장 → 점수 → Export 흐름이 자연스러운지 검증하는 것이다.
```

## 17. 최종 사용 흐름 요약

```text
작업 시작
  ↓
AI와 대화
  ↓
결과 확인
  ↓
VibeGraph로 캡처
  ↓
프로젝트/태그 입력
  ↓
점수/메모 입력
  ↓
리포트 프롬프트 복사 또는 Export
  ↓
다음 작업으로 넘어가기
```

매번 완벽하게 평가할 필요는 없다.

중요한 것은 “내가 어떤 식으로 AI를 쓰고 있는지” 기록이 쌓이는 것이다.
